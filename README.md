# Agenty: a triaging agent
Or, it was what I planned it to be. 
Basically, its a DevOps project just cause I wanted to know how DevOps projects look like. Written in Java, it utilizes podman for the rootless docker vibe, Prometheus for its time-series monitoring, and SpringBoot for the microservice capabilities. 
Right now, it is at it's infant stages, very VERY much incomplete in terms of functionalities, utilizing a set of 3 determined rules and such. Right now, it is *NOT* meant to be up there with the great DevOps monitoring tools that exist out there, but we'll get there eventually(hopefully?).

Language: Java 21 (openjdk)
Tech Stack: Prometheus, Podman (or Docker, whatever), SpringBoot

Hopefully, we'll see where it goes!
